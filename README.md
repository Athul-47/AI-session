# Quote of the Day

A simple app: HTML + CSS + JavaScript frontend, Python (Flask) backend.

## Run it

1. Install Python 3.9 or newer.
2. Open a terminal in this folder and run:

       pip install -r requirements.txt
       python app.py

3. Open http://127.0.0.1:5000 in your browser.

## Files

- app.py          Flask server and the list of quotes
- static/index.html   Page structure
- static/style.css    Styling
- static/script.js    Calls the server when you click the button
- requirements.txt    Python dependency (Flask)

## Add your own quotes

Open app.py and add lines to the QUOTES list.
